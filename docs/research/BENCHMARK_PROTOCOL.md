# M3 — Benchmark Protocol

## Dataset & Scenarios

- 20 synthetic deterministic scenarios covering object movement, stale beliefs, absent observers, relationship changes, possession constraints, room-presence constraints, repetition, narrative novelty, invalid target, and contradictory expected state.

## Metrics Recorded per Scenario

1. Classical validator pass rate
2. Exact optimum agreement
3. Mean utility regret ($\text{optimum\_utility} - \text{selected\_utility}$)
4. Invalid selection rate
5. Exactly-one bitstring sampling rate
6. Reproducibility across seeds
7. Runtime in seconds
