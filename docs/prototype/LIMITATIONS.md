# Technical Limitations & Truthful Scope — M1 Milestone

In accordance with Q-Psi's strict research integrity and evidence policy, the M1 Classical Reference State Engine explicitly acknowledges the following boundaries:

- **No Production Users**: The engine is an internal research baseline; no production end-users exist today.
- **No Customer Validation**: No commercial customer or enterprise contract is claimed for this milestone.
- **No Real-Time 3D**: The prototype is a state-space engine; no 3D graphics, WebGL mesh rendering, or spatial physics engines are integrated.
- **No Voice or Video Synthesis**: Voice cloning, audio streams, and video generation models are decoupled from this classical state kernel.
- **No Autonomous Narrative Director**: Script cues and actions are injected via structured API commands or test scripts.
- **No CUDA-Q Integration Yet**: CUDA-Q and quantum state vector simulation are scheduled for subsequent research milestones.
- **No Real QPU Use**: No quantum processing unit (QPU) hardware is utilized or claimed.
- **Zero Quantum Advantage Claim**: The classical reference baseline operates deterministically without quantum speedup claims.
- **Reference SQLite Storage**: SQLite is used for local single-file prototype storage; production horizontal scaling will require distributed ledger infrastructure.
- **Unbounded Concurrency**: High-concurrency multi-region locking is not yet production hardened.
