# Public Demo Limitations & Truthful Disclosures — M2 Milestone

In accordance with Q-Psi's strict research integrity standards, the M2 Live Persistent-State Prototype explicitly discloses the following boundaries:

- **Early Technical Prototype**: The prototype demonstrates persistent state logic, belief matrix separation, and SHA-256 event replay. It is an early proof tool, not a consumer application.
- **No Production 3D Characters**: The prototype operates in a text and state space; no WebGL, Unreal Engine 5, or 3D character avatars are rendered.
- **No Voice or Video Generation**: Voice synthesis, real-time audio streams, and video model rendering are decoupled from this state kernel.
- **No Autonomous Free-Text Narrative**: Actions are selected via controlled demonstration buttons or structured API payloads.
- **No CUDA-Q or Quantum Hardware in M2**: CUDA-Q quantum state simulation is scheduled for subsequent research milestones.
- **No Quantum Advantage Claimed**: The classical baseline operates deterministically without claiming quantum speedup.
- **Public Demo Session Scope**: Public sessions are temporary demonstration environments with configurable expiration TTL.
